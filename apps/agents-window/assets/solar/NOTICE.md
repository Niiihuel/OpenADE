# Solar Icons attribution

This directory contains 40 unmodified **Linear** SVG icons selected from
`@solar-icons/static` version 2.3.2. Their names match the source package. The
application rasterizes each at the display scale and applies a single semantic
color when rendering; it does not ship altered SVG files. The `alt-arrow-down`
and `alt-arrow-right` files are available for chevrons in menus and file trees.

sidebar credits.
